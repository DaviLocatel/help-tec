# Help-Tec React

Versão React da página Help-Tec criada com Vite.

## Como executar

```bash
npm install
npm run dev
```

## Gerar publicação

```bash
npm run build
```

Os arquivos otimizados serão gerados na pasta `dist`.

## Estrutura

- `src/components/Navbar.jsx`: navegação responsiva e menu móvel.
- `src/components/Hero.jsx`: seção principal de apresentação.
- `src/components/CardDestaque.jsx`: cards com estado de favorito.
- `src/components/CatalogoSection.jsx`: lista dinâmica de produtos.
- `src/components/EquipeSection.jsx`: lista dinâmica da equipe.
- `src/components/Footer.jsx`: rodapé da aplicação.
- `src/App.jsx`: estados, abas, carrinho e modais.
- `src/index.css`: estilos migrados do projeto original.
