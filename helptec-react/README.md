# Help-Tec React

Migração da página principal da Help-Tec para React com Vite.

## Como executar

```bash
npm install
npm run dev
```

## Estrutura

- `src/components/Navbar.jsx`: navegação responsiva e estado do menu.
- `src/components/Hero.jsx`: seção principal de apresentação.
- `src/components/CardDestaque.jsx`: componente reutilizável dos cards.
- `src/App.jsx`: composição da página e lista de destaques.
- `src/index.css`: estilos migrados do projeto original.
