# Help-Tec

Soluções Tecnológicas Avançadas que unem hardware de alta performance e desenvolvimento web moderno para entregar a melhor experiência e eficiência aos clientes.

![Tela principal da Help-Tec](logo.png)

## O problema

Muitos utilizadores e empresas têm dificuldade em encontrar, num único local, tanto peças de hardware de alto desempenho para setups complexos quanto serviços especializados de desenvolvimento web e consultoria em TI. 

A Help-Tec resolve este problema centralizando a venda de computadores montados sob medida, componentes de ponta e a prestação de serviços de criação de sistemas dinâmicos e responsivos, facilitando a digitalização e o upgrade tecnológico dos clientes.

## Telas

| Tela | O que faz |
|---|---|
| **Início** | Apresenta a empresa, os destaques de inovação e leva para os produtos |
| **Sobre** | Detalha a missão e os pilares de soluções tecnológicas da Help-Tec |
| **Produtos** | Vitrine de computadores e peças, com preços e botões de compra |
| **Detalhes do Produto** | Mostra as especificações completas de um item selecionado |
| **Carrinho & Nota Fiscal** | Simula o fluxo de e-commerce, listando os itens e gerando a DANFE |
| **Recursos e Serviços** | Lista as especialidades da empresa (IA, Padrões Web, Suporte Técnico) |
| **Equipe** | Perfil dos desenvolvedores do sistema (Davi Locatel) |
| **Login e Cadastro** | Formulários separados para acesso de clientes e funcionários |

## Tecnologias

- HTML5 Semântico
- CSS3 (Grid, Flexbox e Variáveis - Design System)
- Estrutura Mobile First e Media Queries
- Microinterações de interface sem uso de JavaScript

## Como rodar

1. Clone o repositório para o seu computador:
   `git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git`
2. Entre na pasta do projeto clonado.
3. Dê um duplo clique no ficheiro `inicio.html` para abrir diretamente no navegador, ou utilize a extensão *Live Server* no VS Code.

Não é necessário instalar nenhuma dependência: o projeto é inteiramente construído em front-end estático (HTML/CSS).
